1. 用证据定位并修复输入/会话失败，提供明确中文结束状态，断线后不再派发排队输入。
2. 瞬时网络故障有界自动重连，可取消；不得复活主动停止、撤权或关闭共享的会话。不能直接复用旧grant：保留全新权威授权和有限租约。

<a id="existing-investigations-hypotheses-not-proven-root-cause"></a>

## 已有调查（假设，尚未证明根因）

- `apps/desktop/src/main.tsx` 的viewer在结束状态仍按控制权限运行，继续排队IPC并渲染旧JPEG；点击目标是可聚焦div中的img，未显式取得键盘焦点。
- `remote.rs` 丢弃不少收发错误，只显示泛化 `session ended`；主机InputSink错误只有本机状态，需要向viewer提供有用、有界且无敏感信息的诊断。
- 主机应用ACK期限1s，媒体传输期限400ms，用户截图RTT约91ms。调查抖动容忍，不能扩大旧帧队列或放宽grant。
- 输入通过逐消息单向流连续编号，原生发送锁及前端有界串行队列；验证真实顺序及失焦/停止后释放。
- 当前重连会关闭旧会话grant，需要新请求/决定，除非安全、受限权威协议改动。
- 0.1.1总控加入 `scripts/test-desktop-ui.cjs` 的合成IPC，不是原生/跨网络证据。最后原生打包CI 36511486164通过标题栏、设置、安装/重装/卸载；发布工作流手动触发，公开发布另行执行。
