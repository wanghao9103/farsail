# 文档语言

FarSail 文档和 GitHub About 简介默认使用英文。每个 Markdown 页面顶部都有英文/简体中文切换链接。

<a id="reading"></a>

## 阅读方式

- 从 [README](../README.zh-CN.md) 阅读默认英文介绍。
- 原文件名，例如 `CLIENT.md`，对应英文页面。
- 同名的 `CLIENT.zh-CN.md` 对应中文页面。
- 中文页面的相对文档链接继续进入中文；英文切换链接返回同一文档的英文版。
- 资产、下载、源码文件、外部 URL 与技术标识保留原目标。

语言切换使用普通 Markdown 链接，不依赖脚本、Cookie 或浏览器语言检测。仓库默认入口保持英文。

<a id="maintaining-a-pair"></a>

## 维护双语文档

1. 同时更新英文页与中文对应页。提供完整翻译，不用摘要，也不改变验收结论。
2. 保留双向语言导航和原英文文件路径。
3. 保留可执行命令、API 字段/值、路径、代码示例、提交 ID、校验值与历史测试结果。示意图标签可以翻译，但结构及技术标识不变。
4. 区分已实现、计划中、本地验证、公开发布与未验证状态。历史工作项说明当时版本的证据，不承诺所有当前构建。
5. 保留兼容标题锚点；翻译后的标题增加显式别名，使旧片段及跨语言链接仍可用。
6. 在仓库根目录运行文档检查：

   ```sh
   python scripts/check_docs.py
   ```

检查配对文件、双向语言链接、相对链接、片段及技术内容一致性，不验证应用行为，也不执行浏览器自动化。

翻译在仓库中编写和审查。应用界面语言与此文档约定相互独立。
