<a id="security-and-limitations"></a>

## 安全与限制

- 私钥、长期用户/设备 token 与 grant 不进入 Tauri 命令返回值、浏览器存储或日志。动态 grant 仅由原生层保存。访问刷新串行化；分页每页释放状态锁，让心跳与退出有机会执行。响应上限 1 MiB，游标必须严格前进，最大聚合 10,000 项。
- HTTPS 使用 rustls 默认根证书验证；IP 地址可配置，但需要与 IP 匹配的有效证书。公网 HTTP、URL 用户密码、查询/片段、重定向被拒绝。尚未在实际公网证书/IP 上部署验证。
- 真实远控画面/输入、文件、iroh、跨 NAT、多设备 Windows、Android/iOS 与生产 SMTP 未实现或未验证，不能从本项授权测试推断这些能力可用。
