# 无需电脑的手机应用更新

日期：2026-11-05。发布版本：安卓 0.1.12 / code 13，桌面 0.1.36。

## 行为

安卓原有更新器已经在打开系统安装器前校验更新清单签名、APK 摘要、包名、递增版本号及原安装证书。本次在首页、设置页和登录页增加非弹窗更新提醒，展示下载进度并提供安装入口，不打断远程画面或系统授权页面。

自动检查仍默认开启，成功后间隔至少六小时；自动检查失败后至少等待 15 分钟，手动检查可立即重试。自动下载默认开启，仅在非计费 Wi-Fi 下进行；已保存的选择仍优先，设置中分别提供自动检查、自动下载和仅 Wi-Fi 开关。手动下载不受 Wi-Fi 偏好限制。回到应用且网络满足条件时，可以继续启动已发现版本的自动下载。

进程重启后会重新验证已下载 APK 和原签名清单，离线时也能恢复安装提醒。每次安装仍重新校验清单 / 安装包，并使用安卓的安装来源授权页和系统安装器；屏幕共享期间阻止安装。发布说明改为读取源码中的安卓版本说明文件，不再重复旧功能描述。

## 验证

证据：`.local/release-tabs-20261105/`。

- 安卓 Rust 测试通过，包含签名版本递增与更新来源边界（`android-rust.log`）；JVM、debug / 测试 APK 与 lint 通过，更新提醒设备用例通过（`mobile-ui.log`，其中另一个布局用例的失败保留）。
- 使用兼容当前源码的测试基线（0.0.1 / code 1，原安装证书），在 App 内下载真实公开的安卓 0.1.8 / code 9，通过校验后打开正常的安装来源授权页和系统安装器；结果见 `public-updater-prepare.log`、`update-prepared.json`。
- 结束进程并关闭模拟器两类网络后，首页从已验证缓存恢复安装提醒，不依赖在线检查（`offline-cache-ui.xml`）；离线缓存包可再次打开系统安装器（`offline-installer-ui.xml`）。
- 使用系统安装器实际完成更新。对已安装 code 9 的设备测试确认偏好中的连续性标记保留（`public-updater-verify-retry.log`）。第一次安装后验证启动过早，安卓仍在冻结安装中的包，保留该启动失败，没有算作应用故障。
- 测试仅使用专用 `farsail-memory-api35` 模拟器，未安装、卸载或清除个人手机。初始基线 APK 位于 `update-baseline/`；测试没有修改生产更新通道。

## 发布验收

公开 0.1.12 的 APK、签名、源码来源、固定通道及升级到这一准确版本的流程，已通过下述核验。实体厂商后台策略、任意认证 / 计费网络与无人值守后台下载不在本轮范围内。实现于 App 启动或返回前台时检查，不承诺常驻后台更新或静默安装。

[0.1.12 发布页](https://github.com/wanghao9103/farsail/releases/tag/android-v0.1.12)及[发布流程](https://github.com/wanghao9103/farsail/actions/runs/41959560575)均成功，源码 `82066f9fc8687ee0beb33af0b2f77361148b2228`。公开下载的 4 个 API 附件摘要、Ed25519 清单、原安装证书、非调试包、两个 ABI 的 16 KB 对齐及普通固定通道字节均通过（`.local/android-public-0.1.12/final-verification.json`）。普通地址一致后仅重试失败的发布步骤，版本附件没有改变。该版本与桌面 0.1.36 均作为正式版本发布。
