<a id="baseline-and-scope"></a>

## 基线与范围

- 基线：`024eb05`（2026-09-29）。现有文件传输 Rust/Cargo 改动属于无关的进行中工作，必须保留。
- 写集：`apps/desktop/src/main.tsx`、`apps/desktop/src/style.css`、`scripts/test-desktop-ui.cjs`、本文档。
- 运行时：现有 npm 依赖；1420 端口上的回环 Vite；模拟 IPC/浏览器测试夹具和截图位于忽略的 `.local/ui-verification/`。不修改原生账号配置或远程服务。

<a id="implementation-and-evidence"></a>

## 实现与证据

- 外壳固定导航、标题和通知。设备窗格、远程连接列表和概览活动各自拥有滚动区域。远程画面占据剩余高度。设置使用两列布局；账号登录记录位于账号/密码控件旁。小窗口保留可操作的滚动区域，避免内容被裁切。
- “远程连接”区分当前请求、收到的待批准请求、历史请求、连接他人和邀请。设备名称与中文权限/状态标签替代原始 ID/枚举；完整标识符仍可展开查看。批准状态与传输连接状态分别显示。账号登录记录说明让另一客户端退出登录的作用。
- 邀请权限明确且独立于发出请求的权限。生成时会保存邀请元数据快照，因此修改选择器不会改变已生成代码的标签。
- `npm run build` 通过（TypeScript + Vite）。
- `scripts/test-desktop-ui.cjs` 使用随附 Playwright 和 Chrome 通过测试，仅使用模拟 IPC：现有初始设置/401/离线/取消/批准流程；43 台设备和 47 条请求的溢出夹具；拒绝收到的请求；发出的控制请求与独立的查看邀请；改变选择后仍保留原邀请设备；让另一次登录退出。
- 在 1120×760、900×580 和 680×700 尺寸下验证了六个页面的固定文档/主外壳。概览/设备/连接还断言工作区没有溢出。在 360×580 下，远程连接页没有文档溢出，并保留至少 100px 可用列表高度。短窗口查看器保留至少 120px 的画面区域。
- 已检查 `.local/ui-verification/` 下的截图：本地设备、远程设备、大量设备、连接、邀请、登录记录、概览适配、设置适配、查看器适配、窄布局和紧凑连接。
- 首次测试发现表单控件的无障碍名称含糊；明确的选择标签修复了定位和无障碍问题。随后视觉检查发现，尽管外部外壳稳定，概览仍有溢出且紧凑列表过短而无法使用；两者现已有针对性断言。
- `git diff --check` 通过。现有 Rust/Cargo/文件传输进行中工作未改动。未生成安装程序、未发布版本，也不声称完成了真实对等/原生安装程序验证。本地预览进程已在验证后停止。
