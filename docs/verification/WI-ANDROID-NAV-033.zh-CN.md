# 手机导航 — 0.1.33

原来的返回、主屏幕和最近任务隐藏在更多操作内。现在常显于手机画面下方，全屏也保留；底栏独立占位，保留等比图像和输入坐标。仅查看、控制暂停、断线或不可控制时不能发送导航。安卓尚不支持切换画质或文件传输时，不再为能力缺席显示误导的更新提示；电脑端行为保留。

复用已有认证按键对与安卓辅助功能全局操作。这些导航按钮不需要更新安卓 App 或服务器。

本地 TypeScript/Vite 构建及完整 Chromium 查看器回归通过：三个导航按键对、仅查看拒绝、键盘激活主屏幕且不泄漏 Enter、隐藏工具栏、全屏、竖屏旋转、真实截图四角像素、等比点击与留白拒绝；窗口覆盖 360×640、640×900、1200×800、1920×1080。本地内置 WebKit 可执行文件缺失，Linux WebKit 验收交由安装包流水线。不声称新增实体导航验收。
