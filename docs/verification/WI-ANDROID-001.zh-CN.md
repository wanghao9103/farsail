# WI-ANDROID-001：原生安卓被控端和桌面多窗口

日期：2026-11-02。状态：partial；原生模拟器链路通过，实体手机已安装初始预览；新版应用内升级已在模拟器通过；实体手机新版安装和生产联调待验证。

## 已实现

- 原生 Kotlin 安卓 App、ARM64/x86_64 JNI 库、Android Keystore AES-GCM 凭据存储，以及显式账号/设备绑定。
- 整屏 MediaProjection 前台服务、现有认证传输上的最新 JPEG 画面、有序辅助功能输入，以及本机同意和逐次批准门禁。
- 后台运行独立于 Activity。进程结束后不自动恢复采集。Android 13 及以上不主动弹出通知权限申请，平台仍在系统任务管理器中显示运行中的前台服务。旧系统使用静默通知。
- 电脑端提供安卓导航操作。不同查看窗口分别保存会话访问范围、恢复及取消状态；每台手机接受一个查看端，电脑保留现有十六会话上限。

- 独立账号页面：登录、注册、邮箱验证、服务器设置、应用设置与软件更新分别呈现；异步响应按页面和导航代次隔离。
- 签名 Android 更新：固定独立通道、Ed25519 清单、APK 大小/摘要/包名/版本/安装证书检查；默认自动检查，安装由系统确认。

## 验证

- Rust 主机测试：8 项通过，覆盖两个真实加密 QUIC 手机会话、独立输入与停止、画面 ACK、仅查看禁止控制、输入乱序/重放、旧布局及已取消的开启操作。
- 安卓主机 Clippy 按警告拒绝执行：通过。
- 桌面 Rust：50 项通过、1 项忽略；忽略项需要自建交互式 Windows 环境。包含多窗口访问范围和重连隔离。
- 前端 TypeScript/Vite：通过。查看器/提示/反馈纯状态测试：21 项通过。真实浏览器查看器回归：通过，包含安卓导航按下/松开配对，以及仅查看模式不出现导航。浏览器测试使用合成 IPC。
- ARM64/x86_64 原生 release 构建：通过。ELF 加载段使用 16 KB 对齐。安卓 debug APK 和设备测试 APK 构建：通过。Android lint：通过，无错误；保留依赖版本、启动图标和兼容平台属性等警告。
- Android 15 / API 35 x86_64 模拟器：真实 Keystore 加密/篡改拒绝、JNI 绑定、可见系统录屏授权、主屏幕键/后台运行、移除 Activity 任务、认证 QUIC JPEG 接收及 576×1280 完整像素解码、自建输入框文字和按钮点击、本机停止及通知清理均通过。通知权限保持未授权。设备测试使用合成协调服务响应。
- 模拟器 UDP 转发下，分段 UDP 发送时握手/输入成功但媒体超时；关闭安卓 UDP 分段发送后，真实媒体恢复。桌面传输配置保持原样。实体手机网络行为仍未验证。
- 真实 PostgreSQL 协调服务套件：5 项通过，覆盖安卓在线能力开启、旧心跳代次拒绝、等待批准、非目标设备批准拒绝、文件能力独立及停止屏幕共享后旧 grant 失效。旧协调服务的能力 API 仅允许 Windows 屏幕被控，需要升级。没有新增数据库迁移。
- APK Signature Scheme v2 签名验证和 16 KB ZIP 对齐：通过。Android 0.1.1 已公开发布，APK 不可调试，保留原已安装证书。Actions 41389326495 的独立构建与发布 job 均完成。

本地日志和截图位于 `.local/android-verification`。可复现模拟器脚本为 `scripts/test-android-emulator.py`；拒绝实体设备，使用合成协调响应，仅转发模拟器 UDP 端口，并通过自建输入框验证真实 JNI/Keystore/录屏/辅助功能/QUIC 媒体链路。生产账号批准策略仍由现有协调服务承担。

- 新版独立页面 UIAutomator 测试：通过。登录与注册无服务器/验证码字段，验证页无密码字段，服务器页只呈现地址设置；返回保留邮箱，软件更新独立。1080×2376 实际渲染截图已检查。
- 更新信任 Rust 测试：包含有效签名、篡改、错误公钥、版本及下载来源边界。debug/release 构建及 lint 均通过。
- OPPO / Android 16 / ARM64 已确认初始 versionCode 1 安装并启动；这不代表实体机媒体或新版升级已验收。

- 公开 Android 0.1.1 更新：Ed25519 清单签名、普通固定 feed 与版本清单一致、4 个附件 API 摘要均通过。专用模拟器 bootstrap versionCode 1 使用生产更新代码从真实公开通道下载 code 2，APK 校验后经普通未知来源设置及系统 UPDATE 按钮覆盖安装；同签名测试 APK 验证 code 2、版本 0.1.1、测试偏好数据保留。首次网络下载失败，重试成功；没有把首次失败归因为 APK 损坏。
- 设备更新测试需显式 `-e publicUpdate true` 并指定 `app.farsail.android.UpdateFlowTest#publicDownloadAndSystemInstaller`。bootstrap 使用 Gradle `-PfarsailVersionCode=1 -PfarsailVersionName=0.1.0`；安装完成后 `-e phase verify` 验证保留数据。仅专用模拟器，不得降级或清理真实手机。
