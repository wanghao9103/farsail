Configuration/generated NSIS scripts were checked, but systems lacking WebView2 and system-runtime uninstall/reinstall were not separately simulated. CI does not prove compatibility with all Windows 10/11 hardware. Same-version reinstall was tested; future cross-version/data-format migration still needs dedicated verification. This installer smoke test does not establish real public CAs, two home computers/cross-NAT operation, JPEG performance, or system input.
