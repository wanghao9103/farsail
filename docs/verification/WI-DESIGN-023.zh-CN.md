# DESIGN-023 — 选定的深色桌面界面与可操作失败对话框

基线 `4cd4ecc`；本地分支 `codex/mouse-control-022`。用户选择第二张展示板 `exec-363f15d0-e5df-42cf-86a2-bc90c44345ff.png`，并明确要求在对话框中显示操作错误。实现目标是现有生产 React/Tauri 应用；不要搭建单独网页产品，也不要为匹配模拟概念细节而删除真实能力。

写集：桌面 JSX/样式及图标依赖/锁文件、现有 UI/查看器回归定义及安装程序标题选择器、原生默认传输/恢复配置、候选版 Tauri 版本、设计源和 QA/文档。保留现有鼠标修复。主检出进行中工作/已安装应用/配置/服务器不改动。现有共享 target 是构建缓存；新运行时输出位于忽略的 .local。

视觉目标：石墨色 #171b20/#20262d、银色文本、克制的青绿色 #65cfbc、窄侧栏、常规操作尺寸、表格/列表层次，以及一致的认证/设置/安全/管理员/查看器界面。复用原始徽标；Fluent 图标组件替代字形/自定义 SVG 占位。不会根据生成图像虚构新文件/移动端/管理员账号创建能力。

反馈契约：操作失败使用模态对话框，具有明确且针对操作的标题、简洁说明、折叠的原始技术详情、焦点约束/返回及关闭操作。连接超时提供全新重连操作；页面不出现错误横幅。普通状态/进度保持非模态。查看器轮询不得反复重新打开已关闭的对话框，也不得将对话框按键发送到远程输入。

网络发现：持久化共享恢复的端点 relay=None，而 UI 从 HTTPS 协调服务器推导 8443 端口的默认中继，并跳过对任何已运行端点的启动/重新配置。这可能在启动时静默移除中继回退。将原生默认设置与现有 UI 默认值统一，不重置正在运行端点、不扩大信任、不复用已消费批准。实体环境的超时阶段仍未证实；不要声称源码分析证明用户网络原因。

验证：有意义的模态/键盘/焦点/重试回归、默认恢复配置及现有取消/DPAPI 测试、前端构建、原生测试/Clippy、正常/最小宽度下全部主要页面状态、源码与渲染截图比较及 design-qa.md。在 IAB 自动化不可用时，Product Design 浏览器规则要求浏览器自动化取得明确许可。除非请求发布，否则仅为本地候选版。

用户决定：选择“先实现，不使用浏览器自动化”。继续实现和非浏览器验证；全部浏览器/原生 WebView 自动化和视觉 QA 推迟。`design-qa.md` 记录 `final result: blocked`，不声称已做截图或忠实度检查。更新的 UI 测试仅为定义并经过语法检查；它们不是通过执行的证据。

原生结果：client 21 项单元测试（包括真实临时 DPAPI 恢复/取消及新的 HTTPS/回环/默认中继契约）加 desktop 13 项测试通过。Client/desktop/transport Clippy `-D warnings` 通过。未读取/解密或修改生产配置。HTTPS 恢复现在使用与明确桌面启动相同、已验证的 8443 中继默认值；自定义中继/UDP/强制设置仍为每次运行设置，未新增持久化。UI 显示实际活动端点配置，不把已配置中继等同于连接实际选择路径。这修复已确认的源码级回退缺口；实体首次拨号超时根因仍未证实。

反馈：通用操作错误移入模态警报对话框；登录保留专用对话框，不额外打开第二个全局对话框，也不报告虚假的欢迎成功。技术详情折叠；关闭时恢复焦点；对话框键盘事件不传播到远程画面。输入暂停对话框按代数关闭；鼠标几何问题在显示持续失败对话框前，为自动恢复留出时间。移除使用带稳定设备快照和取消焦点的模态确认。恢复状态保持非模态；失败对话框关闭后仍可手动重连。这些处理器可编译，但其 DOM/焦点行为未经浏览器验证。

首次拨号重试：回调捕获预期目标/权限，使用实时进行中保护绕过过期的渲染 busy/waiting 值，并明确请求全新决定。尽力撤销失败尝试；不会将其作为已消费批准重放。连接列表重试请求新的批准。不自动恢复授权或扩展权限。

前端实现通过 TypeScript 和 Vite 编译。全部操作失败横幅已移除；main/records/admin/viewer 共享模态反馈，包括移除确认。日常状态/进度仍内联显示，不向正常页面布局注入 UI 错误。专用登录错误保留原始技术详情，不重复显示全局错误。现有浏览器回归定义现在针对警报对话框、共享开关、仅模态键盘处理和失败关闭；`node --check` 通过，但有意不执行套件。安装程序生命周期定义只更新概览标题，没有执行。第三方 Fluent 图标许可证包含在公开资产中。最终源码格式/diff 检查通过。随后进行本地候选版打包；没有授权/执行公开发布或真实安装。
