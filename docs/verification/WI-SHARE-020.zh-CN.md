<a id="implementation-and-acceptance-plan"></a>

## 实现与验收计划

1. 带版本且严格验证的 DPAPI 记录，作用域限定于规范服务器、已验证账号、绑定设备及登录会话；新记录/损坏/未知/不匹配记录从关闭状态开始。将记住的意图与运行时可用性分开。
2. 一次有界原生启动尝试，无需设备页交互：验证恢复的登录/身份、心跳、默认传输、交互式显示/采集、能力发布，再启用远程值守。如实暴露待处理/失败。不无限重试。高级传输参数仍仅限当前进程。
3. 明确关闭共享/值守时保存关闭状态，并在网络清理前使旧激活失效。退出登录/身份变化时忘记权限。操作性关闭/采集/网络/传输停止保留记住的偏好，同时取消活动。保留现有主机/值守纪元、能力串行化和延迟批准补偿。
4. 有意义的隔离测试：重建客户端/存储、相同身份恢复和明确关闭的持久化；无效模式及所有者/服务器/设备/会话不匹配；延迟恢复与关闭共享/值守/退出登录竞争；广播前失败；操作停止保留偏好；真实临时 Windows DPAPI。浏览器测试覆盖如实待处理/失败/关闭及运行时传输复用；实际原生 WebView 使用自有配置和模拟服务器，不采集桌面像素或真实输入。
5. 命令：`cargo fmt --all -- --check`；统一 `cargo test --locked -p farsail-client -p farsail-desktop -p farsail-transport -p farsail-media -p farsail-windows --lib`；匹配的 Clippy `--all-targets -- -D warnings`；`npm run typecheck`、`npm run build`；现有浏览器/原生套件加聚焦夹具。临时安装程序 CI 验证内嵌前端、持久化/失败/关闭行为及重装/卸载保留，确保无调试探针。
6. 限定范围源码提交；在现有发布授权下重新 fetch 并非强制推送到 main；在精确源码上触发 `windows-release.yml`。对每次相关 CI 运行设门禁，包括标签触发运行。发布四个 CI 原件，匿名下载并比较大小/SHA256；最后推送证据文档。只沉淀已验证可复用知识，停止自有进程并保留干净检出。

<a id="results"></a>

## 结果

实现单独限定作用域的版本 1 DPAPI 意图、原生一次性启动恢复、运行时传输复用，以及如实待处理/失败/取消 UI。作用域除服务器/账号/设备外还包含登录会话。未知、损坏、超大、缺失或外来记录忽略。值守恢复在主机能力成功发布后执行，并在修改锁下重新读取当前值守意图。高级传输参数不持久化；启动使用现有默认直连端点（`0.0.0.0:0`，未配置中继）。需要自定义中继的部署必须在该次运行重新应用。

明确关闭共享/值守时，先同步取消相关意图再远程清理。关闭替换写入失败时，尝试删除旧启用记录作为安全关闭后备。普通关闭会取消尚未开始的启动任务，同时保留记录。无效认证、退出登录、本地设备替换/移除和服务器变化时忘记权限。解绑其他设备保留记住的意图，同时停止当前操作性运行时。

延迟能力/退出登录回归发现现有补偿缺口：退出登录后使用当前凭据无法撤回旧请求。能力请求现在保留私有的原始服务器/设备/代数快照，并针对该身份补偿；激活也验证完整当前快照。这不向 UI 暴露凭据，也不修改服务器模式/授权 TTL。

本地验证：实际隔离原生 WebView 执行六个普通关闭/重启周期（启用两项、恢复两项、关闭值守、仅恢复共享、关闭共享、重启后均关闭），使用真实 DPAPI 和生产桌面/Capture 构造器。未读取或保存桌面帧，也未发送输入。现有原生查看器/窗口/IPC 隔离通过。浏览器套件通过，包括待处理/失败真实性、取消和复用已恢复端点。完整最终 Rust/Clippy/安装程序/发布证据完成后记录于下方。

统一本地 Rust 套件：52 项通过（client 19 项、desktop 6 项、transport 12 项、media 5 项、Windows 10 项）；两项现有真实帧/输入测试仍有意忽略。包含新增失败保存/删除后备，以及启动调度前取消测试。收紧可选存储失败清理后，client/desktop 25 项测试再次通过。TypeScript、生产 Vite 构建、格式、Clippy 和脚本语法检查通过。新原生六周期证据位于忽略的 `.local/share020-native-verification.json`；现有原生隔离及两套浏览器测试也通过。此处 CI 和公开发布仍待精确源码发布验证后确认。
