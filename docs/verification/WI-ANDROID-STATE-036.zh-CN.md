# WI-ANDROID-STATE-036：系统权限对齐与前台共享自动恢复

日期：2026-11-04。范围：Android Kotlin 客户端；不修改服务端或桌面端。当前为本地修复候选 `0.1.9-state-fix` / code 10，未公开发布。

## 问题与实现

实体 PJE110 / API 36 中曾观察到保存的控制选择为 true，但系统辅助功能未开启、ControlService 未绑定。旧开关直接使用保存选择，导致界面看似已开启，而同账号自动批准实际上关闭。现按保存选择、系统启用列表、真实服务实例及运行控制共同判断开关；系统设置观察器、解绑回调与刷新撤权共同对齐状态。恢复系统权限和连接后重新应用保存选择，主动取消保存选择仍优先。采集中断时不再误报同账号免确认可用，缺少控制权限的入站请求改为恢复入口。

自动共享此前只在主页和共享页、且 phase 为 off/interrupted 时触发，排队前就消耗尝试。现在覆盖主页、设置、共享和更新页，包含上次失败后的新一次前台进入；在真正请求授权时才消耗尝试。忙碌或导航中断不丢失机会；从系统授权返回不算新一次进入，失败不会在同一轮反复请求。已有共享不重复请求；停止、取消授权与登出保持原有退出选择语义。Android 系统录屏确认仍由用户完成，不保存或重放授权数据。

## 证据与边界

- 构建、JVM 测试和 debug/release lint：项目 `.local/android-oppo-sleep/verified-build-resumed.log`；JVM 5 项通过，包含状态组合与既有图像几何。
- 初轮权限/自动恢复实际设备测试通过 2 项；后续增加失败不循环和授权导航检查，最终结果写入同目录 `accepted-device-tests.log`。测试仅在自有 API 35 模拟器，使用合成协调服务及真实 JNI/Settings/系统录屏。
- 重启记忆回归：同目录 `memory-final.log` 记录初轮真实进程替换及取消/停止/身份范围保护通过；最终源码回归另存 `memory-accepted.log`。
- 正式候选包证书与当前实体安装包、仓库固定证书一致，包名/版本、非调试、无 debug provider、双 ABI ELF 与 ZIP 16 KB 对齐已核对，见 `apk-verification.json`。安装与最终汇总见同目录 `installation.json` 和 `verification.json`。

实体更新不等于真实账号连接验收。未验证用户重新授予辅助功能后的物理双机自动批准、拔线长时间后台、厂商权限撤销原因或电源键锁屏后的静默录屏恢复。系统锁屏结束录屏授权的边界保持不变。

最终汇总：JVM 5 项、设备 4 项、真实进程重启与保护项、debug/release 构建和 lint 均通过。实体同证书 install -r 成功，安装后 APK 摘要与交付包一致，首次安装时间保留，MainActivity 启动成功。检查时实体手机仍 keyguard showing=true，没有解锁或替用户确认录屏 / 辅助功能。上述已验证范围 passed，整体 verification 为 partial。早期测试启动失败与工具冲突单独保留；最终夹具等待解锁、排空串行刷新并确认本次服务器地址后再取主页节点。
