# Android controller — 0.1.7

The phone app now has an independent My devices entry and a foreground remote viewer for Windows computers and Android phones. Controller use requires sign-in and a bound device, but no local capture or accessibility permission. Host approval, authenticated device identity, short leases and view/control permissions are reused. No coordinator change is introduced.

The viewer supports fitted direct touch/drag, scroll mode, right click, text and common keyboard actions, local image rotation, and advertised display selection. Android peers expose Back, Home and Recents. Local display rotation uses the same fitted geometry as inverse touch. Frames occupy one latest-value slot; decoded images are bounded, input is ordered and bounded, and stale layout or input-generation commands are rejected. Background, exit, cancellation and sign-out invalidate the outgoing connection synchronously before asynchronous coordinator cleanup. View-only sessions reject all control packets.

Host and controller own separate sessions and capture permission; they reuse one authenticated endpoint. Incoming host subscription ignores outgoing sessions, and stopping local capture no longer tears down an outgoing viewer. Identity changes cancel it. A phone controller owns one foreground viewer; existing desktop multiwindow behavior is unchanged.

Twelve Rust tests passed, including real authenticated QUIC and synthetic coordinator flows for both peer capability types, ACKs, ordered input, paused input, stale geometry/generation denial, view-only display selection, request cancellation, and independent host stop. The controller fixture records synthetic input and never injects into the host OS. Kotlin geometry tests cover all rotations, fitted bands and clamped drags. API 35 owned-emulator UI acceptance passed through real JNI and authenticated QUIC to synthetic desktop and phone peers: actual touch/drag, scroll, text, Android navigation, rotated touch, view-only refusal, background close and pending cancellation. Two Kotlin geometry tests, debug APK/lint and the four-test native host regression completed successfully (the API 36 secure-lock case is skipped on API 35).
