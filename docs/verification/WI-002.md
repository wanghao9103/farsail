<a id="安全与限制"></a>

## Security and Limitations

- Private keys, long-term user/device tokens, and grants never enter Tauri command results, browser storage, or logs. Only the native layer stores dynamic grants. Access refresh is serialized; pagination releases the state lock after each page so heartbeats/logout can run. Responses are capped at 1 MiB, cursors must strictly advance, and aggregation is limited to 10,000 entries.
- HTTPS uses rustls default-root certificate verification. IP addresses are configurable but require valid IP-matching certificates. Public-network HTTP, URL usernames/passwords, queries/fragments, and redirects are rejected. Deployment with actual public certificates/IPs remains unverified.
- Real remote-control images/input, files, iroh, cross-NAT operation, multiple Windows devices, Android/iOS, and production SMTP are unimplemented or unverified. This item’s authorization tests cannot establish those capabilities.
