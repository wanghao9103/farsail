## 实现及构建

- Rust1.93.0、Cargo.lock构建协调服务；upstream iroh-relay1.2.0通过其发行锁文件 `cargo install --locked` 构建。两个Linux amd64镜像已在本机Docker实际构建成功。运行Debian slim+CA，用户10001，迁移嵌入协调二进制。依赖运行镜像固定digest见deploy/production/images.json。
- Linux Compose共享gateway network namespace，协调保持127.0.0.1:8787，数据库仅私网，SMTP回环1025，Mailpit仅宿主回环。公网443/API与8443/relay分离，不将EIP当本地绑定IP。所有服务pull_policy=never。
- 内部准入POST检查私有bearer、已注册公钥、设备bound/enabled、账号verified/enabled及登录未撤销/refresh未过期；数据库2秒期限。upstream没有总HTTP超时，前置回环Nginx连接1秒/读写3秒。公网屏蔽/internal。每客户端RX2MB/s、突发4MB；不使用未实施的accept_conn_limit/burst。
- Bash部署与打包脚本，固定SHA应用tag、依赖完整image-ID派生tag、加载后验证六个ID/平台和附件SHA256。完整归档校验所有配置/层成员，不依赖本机已有镜像掩盖缺层。GitHub工作流仅在真实Compose/身份/relay测试通过后发布预发布附件。
