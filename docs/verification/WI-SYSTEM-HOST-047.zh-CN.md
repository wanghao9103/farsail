# WI-SYSTEM-HOST-047 — UAC 桌面服务与查看窗口恢复

## 请求与此前限制

用户明确要求：其他程序弹出 UAC 时仍能看到并远程操作，任务管理器等系统工具也应能远程打开。0.1.44 只在 UAC 期间暂停普通桌面采集，不能满足安全桌面操作。不能仅凭截图把所有首帧失败都归因为 UAC。

## 实现

Windows 安装包新增 `farsail-system-host.exe`，通过按计算机安装的 NSIS 安装到受保护的 Program Files，注册自动启动的 LocalSystem 服务 `FarSailDesktopHost`。更新钩子先停止旧服务再替换文件；卸载时移除服务。旧的按用户安装目标会重定向至 Program Files，账号与配置存储不变。不会以 SYSTEM 身份执行旧用户目录内的程序，也不会自动删除旧副本。

服务没有网络监听器，不持有账号令牌。它为每个活动交互会话启动独立 SYSTEM 代理。代理工作线程绑定输入桌面，在桌面变化后重建 DXGI 采集。按会话命名的本地管道拒绝远程客户端；两端核对对端进程、可执行文件路径和 Windows 会话，客户端还要求服务端是 SYSTEM。只有受保护目录内安装的 FarSail 进程可请求采集或输入。辅助程序的诊断模式只在内存采集，不能注入输入。远程授权、共享开关、查看或控制权限以及取消仍由桌面运行时负责。不暴露命令解释器或任意进程启动功能，不修改 UAC 策略。

输入请求必须携带新采集画面的桌面凭据。普通桌面的旧点击遇到新出现的 UAC 桌面时会丢弃，直至新桌面自己的帧到达。采集与布局重置仍会使旧坐标失效；连接中断和服务停止时释放本连接注入的按键。主程序保持既有管理员清单；安装服务不表示取消了启动时的授权。

查看窗口新增任务管理器按钮，发送既有有序 Ctrl+Shift+Esc 输入序列，避免快捷键被本地浏览器或窗口截走。切屏超时后继续接收所选目标；错误目标与已被新选择取代的目标仍被拒绝。明确重选同一显示器也会重建采集器。无画面状态提供直接重试和重新连接按钮。

更多操作在桌面端展开为独立的 320 px 侧边面板，主菜单保持 208 px，展开时位置不移动。较小窗口采用更宽且高度受限的滚动布局，保留鼠标离开收起及键盘或表单焦点保留机制。
