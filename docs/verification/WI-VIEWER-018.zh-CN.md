# Windows 预览版 0.1.8 — 默认铺满查看器区域，无留黑边

- 基线 `7213ecf60b5ccaa2c564e18cb16490d354898b06`，干净的受管理 desktop-ui-release 工作树，分支 `codex/viewer-fill-018`。
- 用户反馈最大化时有左右边条，还原时有上下边条。源和客户端宽高比不同；即使图像元素铺满客户区，`object-fit: contain` 仍会产生这些边条。
- 写集：查看器适配模式/指针映射/偏好/CSS、模拟浏览器回归、安装程序版本和交付文档。不修改采集编解码、远程操作系统分辨率、服务器、主检出文件传输进行中工作或生产配置。
- 默认填充将完整源图像拉伸到查看器区域，无裁切；“更多操作”中仍提供保持宽高比的适配，并在本地记住。指针/按钮/滚轮映射必须匹配各模式，模式切换必须取消/释放排队输入。
- 检查：前端构建、宽/高/全屏/还原视口下的截图像素覆盖、两种坐标路径和留黑边拒绝、偏好保留、现有画质/FPS/暂停/终止/只读回归、原生窗口隔离、精确源码 Windows CI 安装及公开哈希。
