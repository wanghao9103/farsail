# RECONNECT-026 — 可见的恢复与保留远程显示器

基线 `8e3e7aa`，受管理的 mouse-control-022 工作树。用户反馈自动重连没有提示，并且会从副显示器返回第一台显示器。保留当前设计及现有禁止浏览器自动化的指令。不修改安装/配置/服务器，也不公开发布。

已确认源码原因：查看器工具栏采用绝对定位，与普通重连通知处于相同顶部位置，可能遮住通知。`ViewerWindow` 按会话 ID 重新挂载 `Viewer`，丢失选择和本地重连通知。每个主机会话以选中的 ID1 开始并立即发送该屏幕；前端直接显示它，选择器也跟随收到的帧。ID1 不保证代表主显示器。

知识回查：现有媒体/输入取消经验适用于全新批准/授权、单调取消、旧 IPC/手势失效，以及区分回环/纯状态检查与实体验证。旧浏览器证据属于历史；当前浏览器/原生 UI 自动化仍被禁止。只读审查确认显示器 ID 是枚举序号，友好名称可能重复；没有稳定硬件身份可用。

写集：`viewer.rs` 当前窗口恢复进度和测试；`lib.rs` 命令注册；前端查看器状态/标记/样式；纯显示器恢复策略和测试；现有查看器 UI 夹具契约（仅定义/语法）；候选版 Tauri 版本；本验证记录及知识沉淀。`remote.rs` 协议、auth/core/client/server 和输入注入仍在计划写集之外。运行时边界：不操作已安装应用或真实桌面输入；构建缓存仍为共享 target。本地输出 `.local/reconnect-026`。

共享工作区写入顺序：首个子代理仅实现 viewer.rs 进度/状态/测试，不构建或提交；根代理同时审查/读取规划。该写入收口后，根代理拥有前端/策略/注册/文档写入及原生缓存/构建。基线如上；代理精确写集仅为 viewer.rs，根代理后续写集避免并发修改。只读审查者可以并行运行。

恢复契约：在退避/请求/新批准/连接阶段独立可见的状态，最多 3 次尝试计数，恢复显示器及简短成功确认。状态命令仅接受调用的查看器窗口，不接受任意 ID；即使请求 ID 变化，它也读取 Binding。不恢复旧授权。取消/拒绝/撤销/身份变化仍为终止条件；符合条件的恢复耗尽后保留明确手动重试。

显示器契约：父窗口保留用户最后意图选择的显示器描述符。新会话暂停画面和输入，直到非空显示器列表、唯一 name+x+y+width+height 匹配、选择请求及目标帧全部就绪。枚举 ID 重新绑定；DPI 不是身份。默认或过期错误屏幕帧在本地丢弃，原生媒体 ACK 继续。原显示器缺失/有歧义时，进入可见的选择屏幕状态，不静默启用默认屏幕控制。手动屏幕切换使用相同取消/帧门禁；异步选择回调和队列不能跨越会话/选择纪元。不虚构显示器硬件身份或对等协议扩展。

验收：有意义的纯状态显示器/帧/意图及原生进度/取消/预算回归，TypeScript/Vite、fmt/diff/Clippy、release NSIS 和源码/副本哈希/版本检查。不运行浏览器/DOM/原生输入或真实双机测试。UI 可见性、物理拓扑变化后的屏幕身份、实体恢复和安装程序生命周期仍待手动检查。原生进度必须准确，不能使用模拟倒计时阶段。

审查细化：原生 manualRetryAllowed 仅在三次可恢复失败实际耗尽后为 true，而非提前遇到身份/授权/目标错误后。前端不可用选择使用空占位项，允许再次选择同一屏幕。选择/等待目标阶段排除重叠选择；超时返回可见手动选择状态。旧输入拒绝回调在关闭会话前必须检查捕获的纪元和组件租约，否则迟到失败可能取消其 Binding 仍持有旧 ID 的恢复。生产 dispatchViewerInput 和纯异步回归覆盖派发与拒绝取消两种情况。自动画质适配等待所选屏幕的真实帧，并使用该屏幕几何信息。

验证：desktop 34 项普通 Rust 测试通过，包括五项新增进度/真实期限/周期/提前错误/取消/ID 替换回归及先前预算测试。Desktop 全目标 Clippy -D warnings 和 Rustfmt 通过。四项先前反馈及十项新增显示器/输入/进度纯 Node 测试通过（总计 14 项）；它们不启动浏览器、DOM、应用或操作系统输入。TypeScript/Vite 和限定范围 Prettier/diff 检查通过。现有浏览器夹具定义现在包含几何信息及新的限定作用域进度契约；node --check 通过，有意不执行套件。有界独立审查发现并修正同屏重试及迟到输入失败取消边界。对等协议/主机输入/授权/客户端不变。只有控制端需要此次更新才能获得新进度/保留显示器行为；屏幕匹配有意要求稳定唯一描述符，而非虚构硬件身份。UI 渲染、原生安装和实体重连仍未验证。
