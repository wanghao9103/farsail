# Windows 预览版 0.1.5 — 让远程桌面充分使用窗口空间

- 基线 `1e49528`，干净的受管理 desktop-ui-release 检出；分支 `codex/viewer-space-015`。
- 用户反馈远程窗口过小。现有原生查看器以 1200×800 打开；多个常驻工具栏/表单行进一步减少图像区域。
- 默认：独立查看器以最大化状态打开。使用紧凑工具栏提供显示/全屏/结束操作；连接诊断和文本工具按需展开。保留完整图像宽高比和正确的留黑边指针映射。
- 用户另外要求分辨率切换和可隐藏工具。默认 HD 为有界 1080p、质量 85、4:4:4 色度；另一选项为 720p。JPEG 字节/像素及载荷速率限制保留。流配置只改变编码，不改变远程操作系统显示模式。
- 写集：原生查看器构建器/冒烟断言、前端查看器/CSS、采集/JPEG 配置处理及限定作用域的媒体配置 IPC、查看器/浏览器/原生测试、发布版本和文档。运行时保留在此检出和隔离测试配置中；主检出的文件传输进行中工作仍分开保留。
- 必需检查：前端构建、视口/帧区域及坐标回归、输入暂停/重试回归、实际原生默认最大化/窗口隔离、Windows 发布安装和公开产物哈希。

<a id="evidence"></a>

## 证据

- `npm run build`、Rust 格式和 Clippy `-D warnings` 通过。Media 4 项、Windows 9 项、Desktop 6 项普通测试通过；2 项交互式 Windows 检查有意单独保留。
- 实际原生 WebView 冒烟测试通过：默认最大化、还原/最大化/全屏/最小化/关闭且主窗口保留。九项禁止的 IPC 操作包括另一会话的媒体配置命令。
- 实际 DXGI→JPEG 编码/解码在内存中通过，未保存截图/私人像素。配置几何检查确认 HD 保留原生 1920×1080、720p 缩小、竖屏处理、不放大及拒绝无效配置。
- 彩色 1px 边缘测试确认 HD 色度/质量显著减少解码颜色误差；仍拒绝过大的 JPEG。对于复杂图像，采集在相同的 1 MB 帧限制内降低质量重试，而不是将超出字节限制立即视为采集失败。
- 两套浏览器测试通过。查看器检查：640×420、1200×800 和 1920×1080 视口边界，图像使用完整客户区，工具栏自动隐藏/显示/固定，按需文本工具，配置 IPC/确认，四分之一/四分之三位置的留黑边坐标，以及原有暂停/重试/终止/只读行为。
- 配置请求/确认使用有界的 13 字节 Media 数据包和单调递增代数。接收器只接受已知预设和预期确认。预设改变时重启采集，生成新的静态帧和布局代数；全屏输入仍通过物理显示几何映射。
- 两台 PC 都需要新客户端才能切换配置。现有采集帧/载荷限制保留；HD 优先保证清晰度，不承诺高帧率。
