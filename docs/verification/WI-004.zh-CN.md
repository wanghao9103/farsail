<a id="implementation-and-local-evidence"></a>

## 实现与本机证据

- `crates/windows` 在枚举的目标显示器所属 DXGI 适配器创建 D3D11 duplication，映射有行间距的 BGRA，按 DXGI rotation 和 per-monitor DPI 处理几何、负坐标，并在内存中降到 JPEG 基线尺寸。`cargo test -p farsail-windows real_dxgi_frame_stays_in_memory -- --ignored --nocapture` 对本机活动显示器建立 duplication，并从真实帧完成 JPEG 编码、协议检查与 RGB 解码；没有保存截图。显示器变更/`ACCESS_LOST` 会关闭会话并保留原因，需重新批准连接。
- `crates/client/tests/coordinator_flow.rs` 在真实 PostgreSQL 的隔离 schema、Axum HTTP 和两个真实 iroh endpoint 上完成注册、设备证明、心跳、普通 API 开启主机能力、跨账号邀请、目标明确批准、认证连接及媒体收发。设置 `FARSAIL_REAL_CAPTURE=1` 时，由目标端取真实 DXGI 帧，JPEG 经会话传到另一端并解码验证尺寸；同测试还传合成 JPEG 并检查负原点。测试不直接改设备表的 `can_host`。
- `cargo test -p farsail-windows real_input_into_own_foreground_window -- --ignored --nocapture` 创建自己的临时 EDIT 窗口，先用 HWND 和进程 ID 确认它处于前台；确认失败的尝试在注入前终止。成功运行时仅发送“FS”、Shift+Home、替换字符“Q”和本窗口中的左键点击，最后释放输入、销毁窗口。右 Ctrl/Alt 和导航键 extended 标志、非正方形四种旋转/row pitch、负坐标、过期布局点击、极小滚轮值及额外输入字段另有合成测试。没有向终端或其它用户应用注入输入。
- `scripts/test-remote.ps1 -SkipServices -RealCapture` 包含格式检查、媒体/Windows/传输/客户端/桌面 Rust tests、完整 Clippy、前端 typecheck/build 与 Windows Tauri 原生 build。项目服务由 `scripts/test-coordinator.ps1` 启动并通过真实 PostgreSQL 回归；测试完成保留原数据卷。传输测试覆盖 view 拒绝 Control、错误身份、租约撤销、强制本地 TLS relay、重放及 reset 的媒体流后继续收到完整帧。`ByteBudget` 与 `wait_for_ack` 测试分别验证持续 payload 上限和慢消费者确认期限；生产 host 只保留最新帧、每帧等待 viewer ACK，媒体发送与控制接收独立运行。
- 最终完整命令退出码为 0：媒体 3 项、Windows 合成 6 项（2 项原生烟测按环境显式忽略）、传输 8 项、客户端单元 8 项和真实服务集成 1 项、桌面单实例 1 项均通过。`cargo clippy ... --all-targets -- -D warnings`、`npm run typecheck`、`npm run build`、`cargo build -p farsail-desktop` 与 `cargo fmt --all -- --check` 通过。受控窗口原生输入测试另行运行并通过。
- 真实 WebView2/debug Tauri IPC 烟测在独立临时配置目录和本机 Vite (`127.0.0.1:1420`) 中返回 `{ok:true,mediaMagic:"FSM1",mediaBytes:679}`，证明前端收到原生 raw binary response。首次启动暴露 `setup` 中直接 `tokio::spawn` 无 reactor 的崩溃，改为 `tauri::async_runtime::spawn` 后复测通过。同目录第二进程未能启动、未写第二份报告，首进程仍运行；文件排他锁的 Rust 测试也通过。测试进程、Vite 与临时配置已清理。

<a id="security-and-actual-boundaries"></a>

## 安全和实际边界

本机页面仅显示查看/控制状态、真实接收 FPS、路径 RTT、显示器选择、明确停止和 TLS exporter 校验码；长期凭据及 grant 不进入 WebView。JPEG payload 预算为持续 1.5 MB/s，帧龄上限 700 ms，消费 ACK 期限 1 秒。预算不包含 QUIC/TLS/IP 开销与重传，尚无公网性能测量。实际画面只经过内存，不进入 Git、CI 工件、日志或公开报告。

Windows 安全桌面/UAC、无人登录、第二台真实 Windows、公网 IP 证书/跨 NAT、移动真机均不属于本机已验证范围。此项用真实双 endpoint 和真实数据库证明普通双端授权及原生采集/解码；WebView IPC 使用合成 JPEG 验证二进制接口，没有把它冒称为第二台机器的真人远控操作。GitHub Actions 无交互桌面，只运行合成媒体、协议、权限与编译测试；真实采集及前台窗口注入仅在本机运行。
