# 安卓远控画面比例 — 0.1.32

竖屏安卓画面继承了电脑端的铺满偏好，被横向拉伸。现在手机显示偏好独立保存，默认保持比例，原电脑偏好保留。渲染与输入沿用同一个缩放几何，拒绝在留白处发起点击，改变显示方式时释放旧输入。

识别到认证后的安卓能力后，窗口仅调整一次，默认不超过当前显示器范围的 640×900 逻辑像素；后续轮询和旋转不会重置用户调整的窗口。保留最大化、还原、全屏和最小化。

本地验证：TypeScript/Vite 生产构建、查看器策略测试、完整 Chromium 合成查看器回归；582×1280 在三种窗口下检查真实截图四角颜色、归一化点击、留白拒绝，旋转至 1280×582，确认偏好独立；桌面 Rust 库测试 50 通过、一个需要专用 Windows 交互会话的测试忽略；Xvfb/Openbox 隔离原生查看器验证实际手机尺寸 640×900、最大化/还原/全屏/最小化和 IPC 隔离。

仅使用合成图像和专用原生窗口，未声称真实 Windows 与手机组合视觉验收或新的中继性能测量。此桌面修复无需服务器升级；安卓锁屏行为与安卓安装包另行处理。
