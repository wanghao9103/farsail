# 安卓防自动熄屏与锁屏恢复 — 0.1.3

原录屏服务只持有 CPU 部分唤醒锁，无法防止显示器自动超时。新增允许变暗的屏幕唤醒锁，覆盖主动开启的跨应用共享；首页明确显示开关，默认开启，关闭立即释放。两种唤醒锁最长八小时，停止或失败时释放；不唤醒或解锁手机。

Android 15 QPR1 以上锁屏会撤销 MediaProjection。onStop 现在保存中断状态和锁屏原因，服务销毁不再覆盖为笼统的关闭。恢复重新取得系统授权，远程控制选择保留；解锁本身不会自动开启共享或弹系统授权。

本地证据：Kotlin/APK 构建与 lint；API 35/36 专用模拟器录屏、后台/任务移除、服务器拒绝后的错误状态；在其他应用等待超过短系统熄屏时限、仅检查当前唤醒锁、关闭保护、手动熄屏及释放。锁屏恢复测试在 Android 16 模拟器设置临时已知锁屏凭据，结束后恢复原设置并仅清除测试凭据。无安全锁的空白模拟器只熄屏时可能仍保留录屏，不能复现带锁实体手机的路径。实际框架回调日志记录共享 → 中断 → 新系统授权 → 共享。

设备测试不操作真实账号与实体手机设置。不声称厂商电池策略、实体手机完整兼容或八小时耐久均已验证；CI 发布与安装版本验收另行补充。
