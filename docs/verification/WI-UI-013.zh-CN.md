# UI-013 — 清晰的操作与完整用户流程

<a id="baseline-and-scope"></a>

## 基线与范围

- 基线提交 `024eb05`，包括尚未提交的 UI-012 改动。保留无关的 Rust/Cargo/文件传输进行中工作。
- 写集：`apps/desktop/src/main.tsx`、`apps/desktop/src/style.css`、`scripts/test-desktop-ui.cjs`、本文件。运行时为回环地址的 Vite 1420，以及 `.local/ui-verification/` 下的模拟浏览器 IPC 夹具。
- 使共享和已批准连接自动准备传输；明确结束连接、邀请、账号恢复、设备管理和管理员操作。保留服务器权限和主机明确授权。

<a id="evidence"></a>

## 证据

- 从设置发起共享是一个操作，会按需准备传输。中继/绑定/强制中继配置位于高级设置；应用配置时明确说明现有本地连接/共享会停止。
- 已批准请求会准备传输，而不是显示不可用的连接按钮。查看/控制连接按钮标明其实际权限。新请求进入当前连接；待处理请求在等待时刷新。批准仍需要主机操作以及原生/服务器授权。
- 请求列表和查看器的结束操作都使用 `revoke_remote`。失败时保留当前步骤以供重试，仅在成功后关闭视图。这有意区别于仅关闭本地传输的做法，后者会保留授权。失败时刷新本地状态，因为原生操作可能已经停止共享/传输。
- 邀请元数据保存在 App 内存中，切换页面后保留，退出登录时清除。复制、折叠/展开和取消是不同操作。生成的元数据始终绑定到原设备/权限/邮箱。折叠不表示服务器端邀请可以无限期使用。未添加剪贴板插件、持久代码存储或服务器改动。
- 密码恢复只有在成功响应后才从邮件请求进入重置表单，再进入登录。导航/操作具有明确标签。原始错误提供易读摘要和可展开详情。重命名/移除提供取消路径；密码/退出登录说明影响。管理员用户/会话/审计字段显示标签，替代原始 JSON。
- `npm run build` 通过（TypeScript + Vite）。`git diff --check` 通过。
- `scripts/test-desktop-ui.cjs` 使用 Chrome 和模拟 IPC 通过测试，保留初始设置/授权/布局覆盖，并增加：恢复请求/重置失败及重试；先启动传输再共享的顺序；已批准请求的传输失败/重试；结束连接失败/重试和撤销授权；邀请剪贴板/折叠/取消与跨页保留；剪贴板失败；取消重命名/移除且不发生修改；易读管理员记录；管理员邀请保留；修改密码后的退出登录以及下次登录时清除邀请内存。
- 现有六页桌面尺寸矩阵和紧凑 360×580 列表高度断言均通过。已检查 `.local/ui-verification/` 下的共享操作、邀请、连接、管理员操作、管理员记录和紧凑连接截图。
- 证据来自前端浏览器/IPC 夹具验证。未测试原生剪贴板、真实对等连接和新的安装程序生命周期。未生成发布版本或安装程序。现有无关 Rust/Cargo/文件传输进行中工作仍在本次改动之外。
