# ALIGNMENT-025 — 桌面文本与控件对齐

基线 `f1c3ac1`，受管理的 mouse-control-022 工作树。用户根据附带的设备页截图要求检查所有页面的对齐。已安装可执行文件的元数据报告 0.1.13；远程主操作堆叠已在未安装的 0.1.14 候选版中修正。不要推断运行中的窗口一定使用所检查的可执行文件。新截图确认页脚文本左边缘不一致，且截图版本中的主操作仍堆叠显示。

只读知识回查：现有桌面工作区笔记适用于保留有限高度、局部滚动、窄窗口可用窗格，以及区分构建检查与渲染证据。其先前浏览器结果描述旧版本，不是当前验证。用户当前指令仍禁止浏览器自动化。所提供截图使用 Product Design 审计指导；其他界面仅进行源码/层叠检查，不声称完成完整视觉审计。没有已保存的 Product Design 上下文。不要将截图中的账号/设备数据复制到已跟踪文件或知识笔记。

工作项：对齐通用文本/图标/状态控件，不重新设计或改变行为。写集：`apps/desktop/src/main.tsx`、`style.css`、`desktop-theme.css`、候选版 Tauri 版本、本验证记录及现有设计 QA 记录。不修改原生运行时/认证/输入、已安装应用、用户配置、服务器或依赖。主检出进行中工作仍在写集之外。缓存：现有 Node 依赖和共享 Rust target；新本地候选版交付到主检出 `.local/alignment-025`。

来自截图/源码及三次独立只读审查的发现：

1. 侧栏状态点加裸文本、br 和 small 使用不同左边缘；账号行的图标/文本列也不同。使用共享固定图标/文本列，并将状态标记居中对齐首行。
2. 成功通知缺少垂直居中，较大的文本关闭字形有不同的行框。使用居中布局和固定的 Fluent 关闭图标点击区域。
3. 强制中继复选框继承网格表单标签布局，控件内容继承粗体标签样式。使用专用水平复选框行，并明确设置普通控件字重。
4. 标题计数仍是带行框外垂直内边距的内联 span。使用对齐标题行和独立居中的徽章。
5. 历史 1050px 侧栏折叠与 900px 主题断点冲突；优先级更高的旧选择器会在宽侧栏内隐藏文字。移除已被替代的侧栏规则，同时保留内容窗格响应式规则。
6. 历史概览 block/start 规则覆盖主题的设备/操作行和右对齐。移除这些覆盖，同时保留窄布局重排。
7. 查看器顶部选择框/按钮/摘要使用不同控件高度。对齐顶部控件，不影响弹出层表单。
8. 主题全局设备列覆盖历史窄窗口单列布局。在 <=580px 时明确恢复单列，并保留有界面板行。使用实际选择器对齐窄窗口标题大小。

最终静态审查还发现，仅图标导航仍与零宽匿名文本项保留 12px 间距，导致图标偏离中心。紧凑断点现在移除该间距并居中品牌图标。恢复概览 flex 行也要求文本列可收缩，并允许长设备名换行；添加 min-width:0、明确间距和可收缩操作列，同时保留局部滚动边界。

覆盖：概览、设备列表/详情/本地共享/批准、连接表单/列表/邀请、共享/传输设置、账号/安全与管理员表格、认证、反馈对话框和查看器窗口外观。未发现其他可达按钮的网格/文本堆叠、摘要多元素布局或设备行/窗口控件居中缺陷。截图/无障碍证据仍仅限所提供状态；没有运行新的浏览器、原生 UI 交互或操作系统输入。

验收：最终层叠/结构的独立静态审查、TypeScript/Vite 生产构建、限定范围 Prettier/diff 检查、release/NSIS 构建和安装程序复制 SHA256/版本检查。不添加映照实现的 CSS 测试。视觉外观、DPI/字体指标、模态焦点和安装生命周期仍待手动验证。仅候选版，未公开发布/安装。
