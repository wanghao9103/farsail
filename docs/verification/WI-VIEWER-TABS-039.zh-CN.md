# 多路远程、会话标签与窗口尺寸保留

日期：2026-11-05。基线：main `e5bddf0`。首次验证时版本为桌面 0.1.35 / 安卓 0.1.10，尚未发布；正式发布结果见下文。

## 改动

- 新发起的远程会话默认加入同一原生窗口的标签页，每个标签保留独立的原生会话绑定、取消、重连实例、屏幕选择与输入代次。应用菜单可让后续连接使用独立窗口。
- 点击标签、在标签条使用方向键、Ctrl+Tab / Ctrl+Shift+Tab、Ctrl+PageUp / PageDown 或 Ctrl+1…9 切换。Ctrl+W / 标签关闭按钮仅结束该连接；原生窗口关闭按钮结束窗口内全部标签。
- 后台标签保持连接与最后画面，暂停前端取帧和解码；原生传输继续确认媒体帧。切走时使排队输入失效，并按序释放已按下的输入，不把上一台手机的按键发给下一台。
- 自动手机窗口适配归属于原生窗口生命周期。重连更换会话 ID、切换标签和远端横竖屏变化都不能覆盖已经设置的窗口尺寸。手机画面的本地旋转在重连后保留。
- 每个查看器只允许一个未完成的状态查询，防止高负载时重叠堆积。基线已包含独立传输租约验证、绑定新代次的证明缓存、解码完成后呈现画面及移除协调服务远程请求限额；本次保留并回归这些修复，不放宽授权。
- 安卓沿用沉浸画布、悬浮工具与跟随远端方向，首帧后 700 ms 收起工具。新增放大 / 缩小和显式铺满屏幕；裁剪、双指缩放 / 平移及触控反变换使用同一几何。空目标查看器不启动连接。

## 边界

昨晚的版本及日志不可得。本次双目标集成为合成环境，原生窗口探针运行于 Linux；实际 Windows 多手机流量、实体手机控制端、整夜运行、厂商后台限制及公网网络环境尚未验收。本次未修改生产协调服务、未发布安装包、未覆盖安装个人手机。
