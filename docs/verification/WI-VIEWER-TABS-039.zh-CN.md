# 多路远程、会话标签与窗口尺寸保留

日期：2026-11-05。基线：main `e5bddf0`。首次验证时版本为桌面 0.1.35 / 安卓 0.1.10，尚未发布；正式发布结果见下文。

## 改动

- 新发起的远程会话默认加入同一原生窗口的标签页，每个标签保留独立的原生会话绑定、取消、重连实例、屏幕选择与输入代次。应用菜单可让后续连接使用独立窗口。
- 点击标签、在标签条使用方向键、Ctrl+Tab / Ctrl+Shift+Tab、Ctrl+PageUp / PageDown 或 Ctrl+1…9 切换。Ctrl+W / 标签关闭按钮仅结束该连接；原生窗口关闭按钮结束窗口内全部标签。
- 后台标签保持连接与最后画面，暂停前端取帧和解码；原生传输继续确认媒体帧。切走时使排队输入失效，并按序释放已按下的输入，不把上一台手机的按键发给下一台。
- 自动手机窗口适配归属于原生窗口生命周期。重连更换会话 ID、切换标签和远端横竖屏变化都不能覆盖已经设置的窗口尺寸。手机画面的本地旋转在重连后保留。
- 每个查看器只允许一个未完成的状态查询，防止高负载时重叠堆积。基线已包含独立传输租约验证、绑定新代次的证明缓存、解码完成后呈现画面及移除协调服务远程请求限额；本次保留并回归这些修复，不放宽授权。
- 安卓沿用沉浸画布、悬浮工具与跟随远端方向，首帧后 700 ms 收起工具。新增放大 / 缩小和显式铺满屏幕；裁剪、双指缩放 / 平移及触控反变换使用同一几何。空目标查看器不启动连接。

## 0.1.38 后续：标签溢出与相邻关闭（未发布）

宽窗口可压缩短设备标签；标签溢出时提供左右翻页和滚轮横向浏览。浏览不选择设备、不展开远程工具。选择设备会让当前标签可见，并在旧面板标签条卸载后保留键盘焦点。窄窗口保留可读的当前设备名称、全部窗口按钮及至少 44 像素的原生拖动区域。关闭当前标签切到右侧相邻标签，最右侧关闭则回左侧；关闭后台标签保持当前选择。原生 host 授权及先同步取消、再异步清理的顺序保持不变。

也定位了上轮 WebKit 超时：文件传输工具栏重渲染后，移出时只有新目标的 pointer-over/move，没有旧目标的离开事件。DOM 悬停已为 false，但保存的悬停标记仍为 true，导致自动收起失效。仅把 mouse-leave 换成 pointer-leave 仍失败。现由捕获阶段的 pointer-move 仅清除陈旧悬停标记并安排收起，不展开工具、不改变远端输入。未修改基线的失败及两次最小实验均保留于 `.local/webkit-toolbar-20261105/`。

证据：`.local/viewer-overflow-20261105/verification.json`。生产构建、17 项查看器策略、桌面 Rust 库（58 项通过、1 项原有忽略）、全目标 Clippy、Rust 格式及 Chromium/WebKit 完整查看器套件通过。新增检查覆盖 1200 像素下 5 个短标签无需溢出、仅本地滚轮/翻页、当前标签可见及焦点、相邻/后台标签关闭，以及 440、320 宽度的窗口按钮和拖动边界。已人工查看宽窄布局截图；此前阻塞的 WebKit 文件粘贴步骤在最终源码的完整套件中通过。

新浏览器探针首轮同时匹配隐藏面板；将拖动定位收窄至当前面板后通过，没有放宽边界断言。Rust 首次链接因对已有绝对前缀的本地 pkg-config 路径叠加 sysroot 失败，修正环境后通过，失败日志保留。以上为原生状态测试及合成浏览器 IPC，不代表实体多手机性能或 Windows 原生拖动验收。未发布新包、构建安卓或部署协调服务。

## 0.1.39：连续切换按操作顺序执行

窗口工作区统一维护切换/关闭的有序队列及单次在途标签查询。用户操作先推进意图代次再立即选择；旧代次或旧生命周期的快照不能覆盖新选择。操作完成后重新读取原生实际状态，包含最新选择失败后的恢复、新打开设备及重连后的会话 ID。effect 重放保留同一个 controller，避免旧查询与新查询重叠。过时选择的失败不覆盖后来结果，但关闭失败即使随后切换成功也仍然提示。

发布源码为 `74a5e41a39754f984eaaf7f8e6a7066e013c314a`，打包结果在下文单独记录。该源码的生产构建、30 项纯状态测试（含 9 项新标签策略）及 Chromium/WebKit 完整查看器套件通过。浏览器故障夹具持有旧 A 快照和 B 操作，在用户选择 C/E 后才放行，验证最后意图保持、最多 1 个在途查询/操作，再覆盖选择失败恢复、关闭顺序及关闭失败后切换成功。既有输入隔离、全屏和标签溢出回归仍包含其中。证据：`.local/viewer-races-20261105/verification.json` 及最终浏览器日志。这些使用合成 IPC，不是实体多手机性能测量。
