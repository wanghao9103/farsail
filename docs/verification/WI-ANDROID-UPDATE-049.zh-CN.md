# 安卓候选包更新

2026-11-11。基于主线 `25a5ac9`，安卓 `0.1.17`，版本号 `18`。保留独立心跳、静态首帧恢复和已授权控制连接唤醒，并从 `45794f9` 重新纳入已验证的本机注册名称显示与临时续期失败处理，避免覆盖较新的主线行为。

传输授权服务的临时失败仅在最后已验证租期内重试。明确拒绝及独立到期检查仍会结束连接，失败不会延长授权。较大的网关错误页仍保留 HTTP 状态。每个查看器继续使用自己的会话和证明上下文；本机名称按当前手机的注册编号查找。

`Android candidate package` 工作流检查客户端、传输、安卓场景、Clippy、Kotlin 测试、lint 和仪器测试编译，然后使用原安装证书构建 `0.1.17-lease1`。继续包含 ARM64 和 x86_64。本机交付前需独立核对构建来源与摘要、APK 签名、包名及版本。准备候选包不等于发布更新通道或安装到手机；真实多机验收仍需单独进行。
