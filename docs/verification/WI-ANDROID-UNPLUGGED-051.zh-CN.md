# 安卓断电离线排查

2026-11-12。用户反馈手机不充电一段时间后，设备列表也变为离线，并非仅远程窗口重连。已连接的 Android 10 手机在运行约 21 小时后，仍保持同一前台在线服务和录屏服务，电池豁免已启用、心跳成功、当前无网络限制。检查时 USB 正在供电，因此不能据此证明断电期间始终在线。

强制深度 Doze 采样 50 秒期间，心跳仍约每 15 秒成功一次；三次采样的心跳年龄分别为 13878、9085、4272 毫秒。测试后恢复 `mForceIdle=false`，深浅休眠状态均为 ACTIVE。物理充电始终连接。这次没有复现用户问题，不能排除 ColorOS 在实际断电后的额外策略。

另发现一个确定的缺陷：`SharingPower` 的 CPU 和屏幕锁只获取一次，八小时到期后没有续期。被测长期运行的服务已不再持有这两个共享锁。改为非引用计数的 90 秒限时锁，每 30 秒续期，且仅在录屏服务运行时生效。关闭屏幕保持、熄屏或进入锁屏后释放屏幕锁；续期不会亮屏或解锁。停止共享时取消续期回调并释放两个锁。在线服务已有独立的限时 CPU 锁续期，不改为无限持锁。

增加容量受限的本地在线诊断记录：充电和休眠切换、服务创建和销毁、最后一次持久化心跳、心跳失败及恢复、长时间调度或心跳间隔。只存时间及粗粒度电源和网络标记，不记录账号、令牌、端点地址或 Wi-Fi 标识。跨进程重建最多保留 24 条事件；成功心跳最多每分钟持久化一次。服务诊断输出增加共享电源锁状态。记录用于接回 USB 后判断暂停、进程替换及网络或认证失败，不绕过厂商限制。

本机通过 16 项 JVM 测试、debug lint 及仪器测试 Kotlin 编译。三项新增虚拟时钟回归测试覆盖 12 小时共享、熄屏或关闭功能及停止时释放，以及停止续期后的限时失效。这不是真机 12 小时电池测试。准备原签名 `0.1.17-power1` 候选包，保留此前真机通过的后台唤醒修复。物理断电后设备列表持续在线的验收尚未完成，不宣称用户反馈的离线问题已经解决。

## 实际中断与固件检查

原签名 `0.1.17-power1` 候选包对应提交 `b9a9cadedba3cf4126ae41e997b622a5a12b9488`，通过构建 `43221552837`；制品 `13945129328`，APK SHA-256 为 `c74a9f2c9bae7c7d3b518d3d239c8c99231927ba97670ab781c6e706effce697`。验证原证书及包信息后覆盖安装到已连接手机，保留原 UID 和首次安装时间。

新记录在实际拔掉 USB 后捕捉到 125177 毫秒调度间隔和 125174 毫秒心跳墙钟间隔。成功心跳停在 21:02:04.839，接回 USB 后于 21:04:10.015 恢复；期间服务和进程未重建。电池历史显示，熄屏约 300 秒后，共享及在线服务的 CPU 锁同时结束，随后 CPU 休眠。协调端源码的设备在线租约为 60 秒，短于观测到的中断。间隔内未记录心跳请求失败。

只读检查手机实际的 ColorOS 应用耗电页面，确认允许唤醒前台、允许完全后台行为、自启动、关联启动四项均已开启。安卓电池豁免和后台运行、保活锁应用操作也均为允许。未修改任何权限或优化开关。

第二次测试模拟断电并强制 Doze 100 秒，心跳继续成功。随后由用户按物理电源键熄屏，保持 USB 诊断连接，模拟断电自然休眠六分钟，在五分钟后复现系统电源锁列表中两个 CPU 锁消失；应用本地 `isHeld` 诊断仍为 true。该 USB 连接模拟中，心跳仍可继续，因此不代表长期实际断电验收通过。两次测试均恢复电池报告；最终 USB 供电、无强制休眠、深浅休眠状态均为 ACTIVE。

只读检查这台手机的 `coloros-services.jar`（SHA-256 `74967f39004e192ae8410a6b2f7f8cc860d5e22db78aaef548fd95371d65bb9d`），定位到 `ColorPartialWakeLockCheck`：熄屏检查在充电时跳过，默认阈值为 300 秒，包含 `whitelistWakelockRelease` 和 `confirmWakelockRelease` 路径，可通过 `releaseWakeLockByGuardElf` 释放锁，并将应用包和 UID 加入禁止持锁列表。这与观测到的供电差异和锁消失一致，但未跟踪到具体运行分支。未修改系统文件，也未加入虚假音频、传感器活动、Shell 白名单或隐藏权限绕过。共享锁续期修复独立的八小时到期问题，尚不能解决该固件限制；可靠断电在线仍需采用平台支持的后台唤醒方案。
