# 安卓后台屏幕唤醒

2026-11-11。接续 WI-049 安卓候选包更新。

USB 连接的 OPPO R17（Android 10、ColorOS V7.1）在物理屏幕休眠时，录屏投影和无障碍服务仍然有效。22:44 的系统日志多次拒绝启动 `app.farsail.android.WakeActivity`，记录 `allowStart = false`、`firewall intercept = true`、`reason = default`，当时前台为桌面启动器。此前应用处于前台时能够启动。同一时段已连接的电脑会话收不到画面。一次前台唤醒成功不能证明后台场景可靠。

Android 8.1–10 上，已授权的控制方现在先由 `ControlService` 直接调用现有的限时亮屏能力，再尝试启动后台窗口。两个操作均检查当前会话、授权代次和屏幕布局授权。授权撤销后不能启动窗口；服务的唤醒锁最多保持 1.5 秒，取消或断开时释放。请求间隔至少一秒。更高安卓版本保留原有窗口行为，不解除密码锁。

在英文临时路径中，本机通过 13 项 JVM 测试、debug lint（零错误、49 条警告）以及仪器测试 Kotlin 编译。四项调度回归测试覆盖后台窗口被拦截、无效授权、亮屏与窗口启动之间撤销授权、限频重试。在原中文 Windows 路径运行 JVM 测试时，所有测试类均无法加载；相同源码在临时路径通过。未在真机运行仪器测试夹具。
