# P2P-019 — 无需重启客户端的有界发现刷新

<a id="authority-and-baseline"></a>

## 授权与基线

- 受管理检出 `desktop-ui-release/远程`，分支 `codex/p2p-refresh-019`，基线 `7fa25fd046a0df70c03dc766db9a34fdf5a74a3d`。排除旧主检出及其已暂停的文件传输/Cargo 进行中工作。
- 用户修正云端 UDP 规则，并确认重启两端现有客户端后实现直连。旧端点精确的缓存过期因果过程仍未证实。本次改动改善重新发现；不声称此前不存在 P2P。
- 写集：transport/client 实现和测试、仅开发用的网络报告功能、原生远程状态、前端路径标签及模拟查看器契约测试、安装程序版本及传输/发布文档。需要原生远程状态，因为查看器从 `RemoteRuntime` 获取实时路径，而非主窗口传输状态。不修改服务器/模式/编解码/配置/凭据。
- 知识回查：设备绑定传输/短租约及 QAD 运维笔记。适用：保留端点身份和待处理授权，保留撤销/TTL 和有界握手，验证真实 UDP 和 TLS。重新验证：Iroh 1.2.0 API 和完整报告触发。历史跨 NAT 缺口与环境有关，不能证明当前用户两端无法直连。

<a id="behavior"></a>

## 行为

- 新的出站和入站握手在现有端点上请求新发现。原生出站刷新发生在获取对等端地址前。
- 使用 `Endpoint::insert_relay` 重新插入完全相同的已配置中继，会排队 Iroh 1.2.0 的 `RelayMapChange`，被归类为 major/full report。不会移除中继、替换端点、复制诊断 socket 地址、轮换身份或拆除传输/授权。已检查该版本缓存源码；可执行 QAD 回归验证此行为。
- 共享端点锁和 30 秒冷却合并全部会话及调用者。Actor 入队有一秒边界。仅中继的活动会话在原生 30 秒维护 tick 上触发重试。良好直连会话不触发维护刷新，状态轮询也从不请求刷新。近期握手可能使下一维护请求推迟到下一个 tick；发现成功不是通过中继继续媒体的必要条件。
- `watch_addr` 在 250ms 合并后发布变化地址，无需等待普通心跳。上传失败在维护/心跳时重试。旧/新端点上传串行执行，并检查生命周期及心跳代数；排队过期快照被拒绝。进行中的 HTTP 上传在发布锁下完成，因为丢弃客户端 future 不会取消已运行的服务器写入。HTTP 保留现有 15 秒边界；协调服务器也继续拒绝过期代数。
- 公开查看器/主界面状态将实际选择的直连/中继路径与调度状态分开：尝试直连、带定期重试的中继回退、刷新调度失败或明确强制中继。不暴露地址、身份、授权、网络报告或推测的 NAT 分类。调度成功不表示 QAD 成功。
- 强制中继和未配置中继跳过 QAD 刷新。现有 16 会话/8 握手上限、租约期限、重放、撤销、控制权限和输入取消保持有效。未使用的批准仍有效。

<a id="verification"></a>

## 验证

- `qad_failure_recovers_on_same_endpoint_without_interrupting_session`：受信任临时 CA、随机回环 HTTPS 中继和保留的 UDP 黑洞。初始真实报告没有 UDP 成功/已发现地址；在该端口启用真实 QAD 服务器并刷新现有源后，获得 UDP 成功及地址。刷新时，一个已认证强制中继对等端接收 80 个不同媒体帧；身份和连接稳定 ID 不变，租约续期。第二个对等端从同一刷新源建立已认证直连媒体，原中继会话仍开放。刷新也保留新的直连连接。不修改外部服务器或系统信任。
- 此夹具隔离 QAD 失败/恢复及中继连续性；同机且未强制中继的对等端即使 QAD 关闭也能直连。因此它不能证明用户两台实体机器上的实时跨 NAT 中继到直连迁移。Iroh 的所选路径仍动态变化；网络修复后的实体迁移是后续验收检查，在 NAT 条件不允许直连时保留中继回退。
- 包含无中继/强制中继跳过、并发冷却、端点关闭、延迟地址上传/替换、旧代数拒绝及待处理批准保留回归。测试仅缩短其私有状态中的调度冷却，以便迅速观察恢复；不替换/重置端点发现或授权状态。
- 本地统一 Rust 套件：43 项通过，有意忽略 2 项交互式采集/输入测试；未采集真实桌面图像或输入。包括 transport 12 项、client 10 项、desktop 6 项、media 5 项和 Windows 10 项。格式、TypeScript、Vite 构建及 Clippy `-D warnings` 通过。
- 两套浏览器测试通过，包括模拟媒体仍可见时的四种调度状态标签，以及现有几何/画质/输入/恢复检查。额外状态等待超过自动隐藏时间，因此夹具在后续画质操作前明确显示工具栏；应用自动隐藏行为不变。
- 实际隔离原生 WebView 冒烟测试通过最大化/还原/全屏/最小化/关闭、主窗口存活及九项拒绝的账号/管理员/跨会话/跨窗口 IPC 操作。仅使用并关闭冒烟测试自身进程/配置。
- 缓存 Iroh 远程状态源码还确认，变化的本地地址观察者会更新 QUIC 候选地址并触发现有连接上的打洞。这是源码级解释，不能替代上方实体跨 NAT 验收缺口。
- 精确源码 CI/安装/公开产物检查记录于下方。
