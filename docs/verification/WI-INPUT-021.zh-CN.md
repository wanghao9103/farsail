- 回查复用先前媒体/输入取消及固定桌面/适配几何笔记。仍适用：会话/授权/共享检查、有界有序输入、释放所拥有按钮、真实注入数量反馈，以及操作系统拒绝时明确暂停。早先单击测试不足以覆盖重复点击/拖动/布局转换。
- 验证模拟且无操作系统输入的过期布局释放复现、释放后继续按钮/移动、不拥有的 UP 拒绝，以及拒绝时保留跟踪状态。浏览器必须验证重复点击、拖出图像、帧变化、失焦/取消和现有暂停/终止/仅查看/适配/画质检查中新发出的平衡输入。交互式原生检查仅针对已验证的自有前台 HWND/PID。发布已测试的精确 CI 原件，并比较匿名公开哈希。

<a id="evidence"></a>

## 证据

- 修正前，模拟的自有按钮 UP 回归以 Geometry 失败，所跟踪按钮仍为按下状态。没有注入操作系统输入。修正后的原生释放仅对本会话实际注入的按钮忽略过期定位；有效释放坐标仍定位光标，不拥有的 UP 不执行操作，被拒绝的 UP 仍被跟踪，直到清理成功。三项回归通过。
- 浏览器使用鼠标 Pointer Events 和按钮掩码转换、指针捕获，以及失焦/丢失捕获时释放/取消。手势必须从图像内开始；外部按住按钮后移回图像不能再次按下对等端按钮。自有拖动坐标夹到源边缘；仅查看、输入暂停、已关闭会话和有界代数取消保持有效。
- 两套浏览器测试和 TypeScript/Vite 通过。新增测试验证 20 次交替左/右点击（40 个新平衡数据包）、同时左/右按钮、图像外释放、新帧布局元数据、窗口失焦和丢失捕获，然后新的点击及键盘输入，媒体仍可见。现有适配/画质/FPS/暂停/终止/只读检查通过。
- 统一 Rust 56 项普通测试通过，两项交互测试仍单独忽略；格式和 Clippy -D warnings 通过。明确的真实输入测试通过：验证前台 HWND/PID、20 次重复点击（包括布局缺失/更新后的 UP）、没有遗留按住按钮、交替两个自有普通窗口，以及继续键盘输入。未操作真实用户应用或私人像素。
- 实际原生查看器隔离通过九项拒绝 IPC/窗口操作及生命周期；改动后，共享偏好重启夹具独立通过。发布 CI/公开产物证据见下方。此改动修正可复现失败路径；不声称它是用户原始、未采集诊断的实体事件的唯一原因，也不绕过提权/安全桌面。
