# FILES-031 — P2P 优先的桌面文件传输

日期：2026-10-10。源码基线 `f97943f`，候选客户端 0.1.21。当前公开客户端 0.1.20 与先前 Ubuntu 登录修复服务端包不包含本次功能；本记录不表示现网已升级或新安装包已发布。

## 行为与授权

Ubuntu 与 Windows 共用原生文件协议、文件 actor 和界面。每次连接使用独立 `files` 权限，每个文件另经接收方原生另存为确认；批准屏幕连接或远程值守不能批准文件。接收默认关闭，重启不自动开启。关闭接收先撤销本机接收操作，退出登录、停用设备、失效授权和安装更新也不能保留正在操作的文件会话。

文件连接复用现有 iroh 端点身份和发现状态。所有未强制中继的文件拨号共享一个最多 3 秒直连窗口：已知 IP 先直接拨号；只有中继地址时可先用可信连接发现和穿透，但文件认证与负载也等待实际直连升级。已有直连立即使用，窗口耗尽才回退到配置的可信 TLS 中继，不重复等待。用户明确强制中继的设置仍有效。路径缓存与实际最终路径分开判断，界面不把中继显示成直连。屏幕传输策略保持原有行为。

数据按 64 KiB 分块并逐块确认，检查严格顺序、长度及 SHA-256；空文件也经完整协议处理。所有发送文件连接共享 4 MiB/s 文件预算。一个连接可以先后传输多个文件，并允许双向传输。拒绝或取消后可继续使用连接；已发布的远端文件不能通过迟到的取消撤销。

本机路径仅保留在 Rust。来源必须为普通文件，Unix 非阻塞打开与打开后元数据复核防止源被换成 FIFO 后无限阻塞。保存通过所选目录能力句柄创建随机私有临时文件，校验后以不覆盖的硬链接原子发布。结束或失败清理临时文件；目录被改名或换成链接时也不追踪到新的目录。发布与本机取消共享锁；已提交状态在锁释放前更新。文件授权携带接收开关纪元，关闭再开启后旧批准及迟到握手都不能恢复，包括握手完成后等待会话表锁的竞态。

## 待验收与边界

物理 Ubuntu/Windows 上真实打开/另存为对话框、公开安装包的安装/在线升级、互联网双机 NAT/P2P 与生产中继、磁盘满/断电、实际大文件性能仍需分别验收。文件系统必须支持硬链接；FAT/exFAT 等保存失败，不提供覆盖或复制回退。不支持目录递归、远程目录浏览、断线续传、压缩和自动执行。提交前检查有效授权；硬链接系统调用已经开始后，时钟到期或独立会话关闭不能与系统调用构成原子事务，也不能撤销已发布文件。临时文件随机命名与目录约束防御远端输入及目录重定向；不承诺防御拥有同目录写权限的恶意本地进程。4 MiB/s 是应用文件预算，不能保证任意链路的屏幕流畅度。

交付与用法见[文件传输](../FILES.zh-CN.md)。必须升级两端客户端和协调服务；旧服务端可能拒绝 Linux 文件能力或错误地关联屏幕能力。本次不改变既有数据库结构，也不重新初始化部署或重置设备。

## 2026-10-20：文件并入远程控制（尚未发布的源码）

基于 `1a618d6` 的工作区改动让文件传输沿用现有 `control` 授权、身份、连接和租约。`view` 仍不能使用 `Channel::File`，独立 `files` 授权也不能访问媒体或输入。屏幕运行时继续作为唯一传输 reader，将有界文件帧转交独立 actor，文件 IO 不会抢走媒体帧；文件 actor 失败只关闭文件通道，不关闭正常的远控连接。

本机文件剪贴板支持 Windows `CF_HDROP` 和 Linux `text/uri-list` / `x-special/gnome-copied-files`，一次最多 32 个普通文件，顺序发送。只有原生私有临时目录内已完成完整性校验的任务 ID 才能加入远端剪贴板。`FSFC1` 声明能力，`FSCP` 准备、粘贴和结果使用不同序号，并绑定已处理的输入顺序及准备时的前台窗口。原生命令校验查看器所属会话，WebView 不获得来源/目标路径或通用文件系统权限。Windows 粘贴前重新检查授权与输入上下文；成功仅表示已发送粘贴，不代表 Explorer 后续复制完成。

本地检查：client 50 通过、1 项无关密钥环测试忽略；desktop 49 通过、1 项隔离剪贴板测试在普通套件中忽略；Windows portable 9 通过；transport 18 通过。新增真实认证 QUIC actor 测试在 Control 授权下传输多块文件和空文件，交错发送媒体数据，拒绝未接收任务 ID，并确认停止文件后共用连接仍可用。隔离 Xvfb GTK 测试另行执行，两种 Linux 剪贴板格式均通过。Windows 剪贴板代码通过 `x86_64-pc-windows-gnu` 交叉检查。Clippy 零警告、TypeScript/Vite、格式和 53 对双语文档检查通过。既有 Chromium 桌面回归及 Chromium/WebKit 独立文件回归通过。查看器检查覆盖剪贴板分派、防重复、原生选择器分派、普通远端粘贴兜底、失败保留画面及旧端能力门禁。
