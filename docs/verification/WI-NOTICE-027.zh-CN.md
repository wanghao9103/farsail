# NOTICE-027 — 关闭查看器窗口时移除其打开通知

基线 `fd66061`，受管理的 mouse-control-022 工作树。用户标出关闭查看器后主页面的“已打开独立查看器”成功横幅。将截图目标解释为远程窗口通知生命周期，而非操作网络端口的请求。主 App.act 将成功消息保留至下一操作；Devices 还单独保留 connectionNote。两者都需要按作用域清理。

知识回查：先前模态反馈/异步取消笔记适用于全部产生路径、过期回调、生命周期所有权，以及区分纯检查与 UI 证明。用户当前禁止浏览器自动化的指令持续有效。截图包含账号/设备数据，不复制到已跟踪文件或笔记。

写集：viewer.rs 独立窗口实例身份/状态和回归；lib.rs 命令注册；main.tsx 两个限定作用域的通知消费者/全部查看器打开产生路径；纯通知租约/测试；现有浏览器夹具契约（仅语法）；候选版版本；文档/知识沉淀。不修改服务器、传输、认证、输入协议、已安装应用/配置，也不公开发布。缓存为共享 target；本地输出 `.local/notice-027`。

共享写入：首个子代理仅写 viewer.rs，不构建/提交，根代理同时读取和规划。交回后，根代理串行拥有其他文件和共享 Rust 构建缓存。原生身份在进程内对每个 Binding 唯一，重连会话 ID 改变后仍保留。仅主窗口的状态查询接受实例身份，不接受可变会话 ID。关闭时先移除/取消绑定，再异步清理；已经关闭中的窗口不能报告为成功的现有查看器。

前端设计：打开返回带类型的本地查看器通知租约。全部三个产生路径通过 act 返回该租约，Devices 也保留它用于详情反馈。通用操作消息不限定作用域。发布前验证，仅在有限定作用域通知时每 500ms 检查；直接读取本地状态，不轮询网络/账号。租约关闭具有单调性；未知/失败的状态读取不表示已关闭。替换/卸载时停止回调/计时器并匹配捕获的所有者，避免旧结果清除其他通知或通用通知。重连保留相同实例；最小化/聚焦不会关闭它。

验收：有意义的原生身份/取消及纯延迟查询/发布前关闭/替换/多所有者/失败回归；前端构建、fmt/diff/Clippy；NSIS/源码副本哈希/版本。不运行浏览器、实际原生窗口交互、安装生命周期或实体远程测试。窗口关闭 UI 时序/外观仍待手动检查。

细化：操作通知结构为消息加可选的带类型查看器租约；横幅和详情都使用按所有者匹配的函数式清除。全部三个路径的打开/返回均返回相同租约类，普通 API JSON 无法获得通知所有权。发布在状态验证前后检查操作代数，旧操作的 error/finally 回调不能覆盖较新操作 UI。成功创建后立即被用户关闭的窗口返回其实例供验证，而非报告新的失败对话框；待处理/关闭中的现有窗口仍拒绝将聚焦报告为成功。

结果：前端 TypeScript/Vite、限定范围 Prettier/diff 和 Desktop Rustfmt/Clippy -D warnings 通过。Desktop 37 项普通测试和 21 项纯 Node 测试通过（7 项新增通知测试加 14 项先前显示/输入/模态策略测试）。新增回归覆盖重连/替换时的窗口身份、待处理/取消/缺失状态、发布前关闭、并发乱序查询、较新通用消息所有权、独立窗口、未知查询失败和已卸载观察者。状态查找在原生窗口管理器检查前克隆所跟踪绑定，保持注册表锁的持有时间短。现有主 UI 夹具模拟实例返回/状态契约，仅进行语法检查。独立只读审查未发现遗漏产生路径或阻断问题。UI 时序/渲染及安装程序生命周期仍未验证。
